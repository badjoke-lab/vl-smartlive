## Delivery and signal integrity

- `release:direct` generates local Node-served preview folders/zips, **not** a Windows installer or Android APK. The `mobile` ZIP bundles Android source as an extra directory, not an installable Android application.
- `check-ui-smoke.mjs` checks the presence of text tokens in files; `check-local-urls.mjs` checks HTTP 200 and text snippets. Neither clicks GUI controls nor checks actual stream/OBS connections.
- `apps/obs-bridge/package.json` contains deferred Electron dev/build scripts. Without usable build targets, `apps/obs-bridge/src/main/index.ts` is not a shipping Electron application.
- `apps/pc-standalone/src/behavior.js` has local UI behavior and sanitization tests but there is no complete sender test; `apps/mobile-android` is not included in Node CI.
- **Status reporting requirement:** mark any fixture, synthetic status, mock OBS session, planned write, static capture, and placeholders as DEMO / PREVIEW, never as real source state.
