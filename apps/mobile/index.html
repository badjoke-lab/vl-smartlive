First-run guide

  1. Tap Load bundled sample data to enable comments, Raw/Radar, session/log/report.
  2. Review limitations and permission messaging before camera/mic checks.
  3. Tap camera/mic buttons only when ready. No automatic access on page load.
  4. Set RTMP/RTMPS target. Browser-only v1 keeps streaming inactive.
