# SmartLive Console

Static Web Console shell for SmartLive / VL SmartLive.

## Purpose

The console provides a local browser view for checking SmartLive session outputs.

It provides:

- Local-first landing layout
- Sample session summary
- Raw / Radar comment tabs
- Report preview
- App links for Mobile / Studio / OBS Bridge
- Privacy note

## Local check

From repository root:

```bash
pnpm run dev:console
```

Then open:

```text
http://localhost:4173/apps/console/
```
